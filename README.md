# Agent Skills

Agent Skills is an open repository of Agent Skills designed to standardize and share effective task-solving patterns for AI agents.
By encapsulating domain knowledge, operational procedures, and automation logic into reusable skills, AgentSkills enables agents to learn, reuse, and scale capabilities across projects and applications.

| [Skill Creator](https://github.com/anthropics/skills/tree/main/skills/skill-creator)    | Guide for creating effective skills.
